# Photographs

Three photographs are referenced by the site. Drop the files in here with
these exact names and they appear automatically — no code changes.

| File | Where it appears | Frame |
| --- | --- | --- |
| `latte-flight.jpg` | Home, The Café section | portrait, 4:5 |
| `shelves.jpg` | Home, The Shelves section | portrait, 4:5 |
| `book-box.jpg` | Book Box page | portrait, 4:5 |

**Shoot or crop to 4:5 portrait.** Anything else still works — the frame
crops to fill — but the centre of the image is what survives, so keep the
subject centred.

**Size:** 1000 × 1250px is plenty. Export JPEG at around 80% quality and
keep each file under roughly 300KB; these load on phones over café wifi.

**They are displayed with a sepia wash** that lifts to full colour when
someone hovers. Warm, evenly lit shots suit this best. Very dark or very
contrasty images tend to muddy under the treatment.

Until a file exists, that slot shows a drawn placeholder instead. The page
is never broken by a missing photograph, so these can land one at a time.

## Alt text

Each image already carries alt text describing it for screen readers and
for anyone whose images fail to load. If the photograph you supply differs
from the description, update the `alt` attribute in `index.html` or
`book-box.html` to match what is actually in the frame.
